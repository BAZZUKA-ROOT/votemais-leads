# Objeções (adaptado de Harvey · objection_handling)

## LAARC
**Ouvir → Reconhecer → Avaliar → Responder → Confirmar.** O objetivo não é "vencer" a objeção, é entender a preocupação.

## Diagnóstico antes de responder

- **Reflexo** ("não tenho interesse" segundos depois): não rebata conteúdo que não leram. Agradeça e encerre, ou ofereça uma única informação útil.
- **Condição** ("já fechamos com outra plataforma este ano"): é um fato. Pergunte se pode falar na próxima edição e agende o follow-up para lá.
- **Cortina de fumaça** ("é caro" sem perguntar preço): a objeção real costuma ser prioridade ou confiança.
- **Objeção real** (específica, envolvida): é sinal de compra — responda com substância.

Resposta curta → responda mais curto ainda. Resposta longa → responda com conteúdo.

## As 4 categorias, adaptadas

**Orçamento** — "não temos verba"
- "Entendo. Como a VoteMais aceita votos pagos via PIX e cartão, a própria votação pode ajudar a arrecadar para o evento. Quer que eu explique como funcionaria no de vocês?"

**Autoridade** — "quem decide é a comissão/prefeitura"
- "Sem problemas! Quem seria a melhor pessoa para conversar? Posso mandar um resumo curto para você repassar."

**Necessidade** — "fazemos pelo Instagram/formulário"
- "Faz sentido, é o mais comum. Como vocês têm resolvido a conferência dos votos e as reclamações de perfis falsos? É justamente aí que a VoteMais costuma ajudar."

**Momento** — "agora não, o evento é só no fim do ano"
- "Tranquilo! Quando vocês costumam definir a votação? Posso te procurar nessa época."

## Regras

1. Nunca discutir. Uma tentativa por objeção; se insistirem, respeite.
2. "Não tenho interesse" é final: agradeça e encerre.
3. Sempre termine com uma pergunta ou próximo passo leve.
4. Iguale formalidade e energia de quem respondeu.
5. Se não for o perfil, diga — credibilidade vale mais que uma venda.

## Limites éticos (prevalecem sobre tudo)

- **Pedido para parar** ("pare", "não me mande mais", "me tira da lista") não é objeção: confirme a remoção, adicione à lista de supressão, mova para *Sem interesse*.
- **Irritação** → desculpa breve, supressão, fim.
- **"Como conseguiu meu número?"** → resposta factual (contato publicado em <fonte>), oferta de remoção imediata, supressão.
- **"É robô/IA?"** → verdade, imediatamente: a mensagem foi preparada com ajuda de IA e revisada/enviada por uma pessoa.
- **Nunca inventar** clientes, cases, números, prazos ou escassez.
